# 🛍️ E-Commerce Website

## 📌 Project Overview

This project is a responsive E-Commerce Website developed using HTML, CSS, and JavaScript.

The main objective of this project is to create an interactive online shopping experience where users can browse products, search products, apply filters, sort products, and manage their shopping cart.

This project is based on the Dinevo HTML template and has been customized for E-Commerce functionality.

---

## 🎯 Project Objective

The main objective of this project is to practice and implement front-end web development concepts using HTML, CSS, and JavaScript.

The project focuses on product browsing, product management, shopping cart functionality, search, filtering, sorting, CRUD operations, and LocalStorage.

---

## 🚀 Features

- 🏠 Home Page
- 🛍️ Shop Page
- ➕ Add Product
- ✏️ Edit Product
- 👁️ View Product
- 🗑️ Delete Product
- 🛒 Add to Cart
- ➕ Increase Quantity
- ➖ Decrease Quantity
- ❌ Remove from Cart
- 💰 Total Price Calculation
- 🔍 Product Search
- 🔽 Product Filter
- ↕️ Product Sorting
- 💾 LocalStorage
- 📱 Responsive Design
- 📞 Contact Page

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- LocalStorage
