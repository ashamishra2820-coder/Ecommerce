# 🛍️ E-Commerce Website

## 📌 Project Overview

This project is a responsive E-Commerce Website developed using HTML, CSS, and JavaScript.

The main objective of this project is to create an interactive online shopping experience where users can browse products, search products, apply filters, sort products, and manage their shopping cart.

This project is based on the Dinevo HTML template and has been customized for E-Commerce functionality.

---

## 🎯 Project Objective

The main objective of this project is to practice and implement front-end web development concepts using HTML, CSS, and JavaScript.

The project focuses on product browsing, product management, shopping cart functionality, search, filtering, sorting, CRUD operations, and LocalStorage.

## 📄 Website Sections

### 🏠 Home Page

The Home page is the main landing page of the website.

It provides the main content and navigation to different sections of the E-Commerce website.

### 🛍️ Shop Page

The Shop page displays the available products.

Users can browse products and use search, filter, and sorting functionality.

### 🛒 Add to Cart

The Add to Cart section allows users to manage the products they have selected.

Users can:

* Add products to the cart
* Increase product quantity
* Decrease product quantity
* Remove products from the cart
* View the total price

### 📞 Contact Page

The Contact page provides contact information and allows users to get in touch with the website.

## ▶️ How to Run the Project

Follow these steps to run the project:

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open the main `index.html` file.
4. Install the **Live Server** extension in VS Code.
5. Right-click on `index.html`.
6. Select **Open with Live Server**.
7. The E-Commerce website will open in the browser.
